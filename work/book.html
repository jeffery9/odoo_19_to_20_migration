This cookbook lists the code replacements required when moving custom modules from Odoo 19.0 to Odoo 20.0. It covers Odoo Community and Odoo Enterprise. Each entry is a 19 → 20 change: a model, field, method, view xpath, QWeb directive, HTTP type, or JavaScript API that 19 accepted and 20 does not.

The replacements are taken from the official Odoo 19.0 and 20.0 source trees ( odoo/odoo Community, including base and the standard addons, and the matching Enterprise addons).

Further 19 → 20 rules on this file:

  • model_id/id from 19 is not model_id . The 20 column needs the technical

name.

_name listed in _inherit requires that parent model to exist in the registry. CE a module that _name = 'helpdesk.sla' and also _inherit = 'helpdesk.sla' fails unless EE helpdesk is installed. CE-only graphs use _name only. EE graphs that load Enterprise Helpdesk keep _inherit .

Two Many2many fields on the same model to the same comodel, without relation= , collide on 20. Set relation= on at least one.

A 20 compute must assign every record. A 20 compute must not return a value dict. Stored and non-stored fields cannot share one compute method.

method=True on a computed field is invalid. tracking= on a related field requires mail.thread . Related Selection must not re-declare selection / default / tracking . placeholder= is XML-only.

A required SQL column without default= raises NOT NULL on create. required=True on a new Many2one cannot add NOT NULL when the table already has rows.

self.env['some.model'] is a recordset. _inherit is on self.env.registry['some.model'] .

COPY, WRITE ORDER, AND TRANSLATIONS

A Char field named name now defaults to copy=mark_as_copy('name') . Duplicating a record appends “(copy)” to that value. Override copy= when the 19 behaviour must stay a plain copy.

from odoo.tools.translate import mark_as_copy
name = fields.Char(copy=mark_as_copy('name'))
code = fields.Char(copy=False)

create() and write() run field inverses in (field.write_sequence, field definition order) . Custom inverses that assumed 19 order can break. Set write_sequence= when two inverses must run in a fixed sequence.

partner_id = fields.Many2one('res.partner', write_sequence=10)

Reading a One2many or Many2many returns only records the user can access. Code that counted or mapped the full relational cache of forbidden ids will see a shorter recordset.

Module translations are stored in that module’s PO. 20 no longer dumps them into base . Export and import translations per module.

WEBSITE ON THE ENVIRONMENT

CE + EE when website is installed. 19 model code often used request.website . 20 Environment exposes env.website from context['website_id'] . Prefer self.env.website in models. request is not bound in report parsers and several ORM contexts (Chapter 4).

# 20
website = self.env.website

DOMAIN OPERATOR ACCESS

20 adds the domain operator access . It is valid on id and on Many2one fields. The value is 'read' , 'write' , 'create' , or 'unlink' . Use it when a domain must keep only records (or related records) the user may operate on. It does not work on properties.

# 20 — current user can write the partner
Domain('partner_id', 'access', 'write')
# 20 — current user can read this record
Domain('id', 'access', 'read')

This operator is useful in ir.access.csv domains (Chapter 1) when the rule must follow comodel rights.

6. SQL reports

BACK TO CONTENTS

CE + EE

_TABLE_QUERY → _TABLE_SQL

19 SQL views set _auto = False and define _table_query (attribute or method). 20 removes _table_query . The lint on 20 is: overwrite _table_sql . Return odoo.tools.SQL .

# 19
_auto = False
def _table_query(self):
    return self._query()
# 20
from odoo.tools import SQL
_auto = False
def _table_sql(self) -> SQL:
    return SQL("(%s)", self._query())

sale.report on 20 is the reference: _table_sql() builds a Query and returns query.subselect(...) . A module that only migrated _select() / _group_by() to SQL still fails if it leaves _table_query in place.

_SELECT() AND _GROUP_BY()

_select() and _group_by() return odoo.tools.SQL . A Python string cannot be concatenated onto that value. LiteralSQL has no .code .

from odoo.tools import SQL
